# Modern PlatformIO Demos

This folder archives newer Arduino and Teensy sketches rescued from sibling repos before they get a cleaner home in the main taxonomy.

These are not all polished end-user projects. Some are direct snapshots, some are minimal demo surfaces, and some preserve rough prototype logic because that history is worth keeping.
