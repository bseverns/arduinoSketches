# Holding

This folder is for sketches that deserve to stay visible and preserved, but do not yet have a clean or defensible home in the main taxonomy.

Use `holding/` as an intentional waiting room, not as a dumping ground.

Current sub-buckets:

- `uncategorized/` for older sketches that still need a better domain claim
- `modern-platformio-demos/` for newer controller and installation snapshots rescued from sibling repos
