# Experiments

This folder is for sketch families that show a real progression instead of a single one-off build.

Current families:

- `algorithms/`
  - Algorithm-first sketches and studies whose main identity is the code idea rather than a specific hardware build.
- `greybox/`
  - Relay, motor, and control experiments that evolved across several sketch revisions.
- `synthesis/`
  - Sound-generation families such as Mozzi controls, ATTiny85 sketches, and Auduino variants.
- `playback/`
  - Sampler and shield-based player variants.
- `robotics/`
  - Families centered on robot/control builds.
- `rhythm-boxes/`
  - Drum-machine, sample-loop, and rhythm-box builds.
- `sensors-actuators/`
  - Hardware-facing sketches for triggers, sensors, switches, and simple outputs.
- `sequencers/`
  - Step-based pattern and note-sequencer builds.

Rule of thumb:

- Put iterative work here.
- Keep each family in its own subfolder.
- Leave standalone sketches at the repo root until a real family line appears.
