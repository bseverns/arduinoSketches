# Sensors And Actuators

This domain is a holding area for hardware-facing sketches whose core purpose is sensing, switching, or driving an output.

Current members:

- `Blink_baby/`
- `trinketInstall_baby/`
- `lineIn/`
- `baby_switch/`

Rule of thumb:

- Put input/output hardware sketches here when they do not yet form a clearer family.
- Promote them into a more specific family later if a real lineage appears.
