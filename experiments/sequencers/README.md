# Sequencers

This domain is for sketches whose core identity is explicit step sequencing, pattern editing, or clocked note playback.

Current members:

- `ArduinoPunk/`
- `SimpleZAR/`
- `sixteen_step_sequencer/`

Rule of thumb:

- Put step-sequencer and pattern-sequencer builds here.
- Leave rhythm-adjacent but non-sequencer sketches such as `Musicator` or unclear drum builds such as `drum8` outside this folder until their role is clearer.
