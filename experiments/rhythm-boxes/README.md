# Rhythm Boxes

This domain is for rhythm-led builds such as drum machines, loop boxes, and sample-trigger boxes that are not primarily note sequencers.

Current members:

- `drum8/`
- `ANDI-master/`

Rule of thumb:

- Put drum-machine and loop-box builds here.
- Keep explicit step sequencers in `experiments/sequencers/`.
- Leave rhythm-adjacent but non-rhythm-box sketches such as `Musicator` outside this folder until the fit is clearer.
